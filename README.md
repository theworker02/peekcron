# peekcron

Peek identifiers and cron tokens for idempotent workflows.

**Site:** https://theworker02.github.io/peekcron/

## Install / run

```bash
git clone https://github.com/theworker02/peekcron.git
cd peekcron
node src/cli.js
node --test
```
